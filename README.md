# Frontend Landing Page

A landing page built from scratch with HTML and CSS, practising turning a design layout into clean code.

## Sections
- Navigation bar (Home, About, Services, call-to-action button)
- Hero section with title, subheading and button
- Hero image
- Testimonials section with feedback cards
- Article section with image cards

## Tech Stack
HTML5, CSS3 (Flexbox), Font Awesome

## Project Structure
```
frontend_page/
├── index.html    # page structure
├── project.css   # styling
└── *.png, *.jpg  # hero, heading and article images
```

## Run Locally
```bash
git clone https://github.com/SanyaSajid/frontend_page.git
cd frontend_page
```
